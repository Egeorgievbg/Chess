# ♟️ Шахмат за деца - Уеб приложение

Интерактивна платформа за обучение и игра на шахмат, специално разработена за деца. Приложението е с приятен интерфейс, образователни уроци и възможност за игра против компютър.

## 🎯 Характеристики

- **👤 Профилна система** - Регистрация и вход за всеки играч
- **🎮 Интерактивна игра** - Играйте срещу компютър с три нива на трудност:
  - Лесно - случайни ходове
  - Средно - предпочита атаки
  - Трудно - оценява позициите
- **📚 Образователни уроци** - Научете основите на шахмата
- **🎨 Модерен интерфейс** - Приятелски и интуитивен дизайн за деца
- **💾 Съхранение на игрите** - История на всички ваши игри
- **👥 Социални приятели** - Покани към реализиран онлайн режим, отметка дали приятелят е на линия и персонални нотификации, които ви помагат веднага да стартирате игра със съществуващ контакт

## 🛠️ Технологии

- **Backend**: Python 3.x с Flask framework
- **Database**: SQLite
- **Frontend**: HTML5, CSS3, JavaScript
- **Chess Engine**: python-chess библиотека
- **Authentication**: Flask-Login

## 📋 Изисквания

- Python 3.7+
- pip (Python package manager)

## 🚀 Инсталация и стартиране

### 1. Клониране/копиране на проекта
```bash
cd d:\WORK\Chess
```

### 2. Инсталация на зависимостите
```bash
pip install -r requirements.txt
```

### 3. Стартиране на приложението
```bash
python run.py
```

Приложението ще бъде достъпно на: **http://127.0.0.1:5000**

## 🎮 Как да используете приложението

### Регистрация
1. Кликнете на "Регистрация" в навигацията
2. Попълнете потребителско име, email и парола
3. Потвърдете регистрацията

### Вход
1. Кликнете на "Вход"
2. Въведете потребителското име и парола

### Начало на игра
1. След влизане, кликнете "▶️ Начни нова игра"
2. Изберете:
   - Цвят (бял или черен)
   - Ниво на трудност
3. Кликнете на фигуру, която искате да преместите
4. Кликнете на целевия квадрат

### Преглед на уроци
- Кликнете на "📚 Вижте уроци" за образователни материали
